# 可直接复制的提示词

插件安装后，`prompts/system.md` 会自动作为「网络工程实验教练」的系统提示注入，不需要每次粘贴。下面这些是**用户侧提示词**，按场景复制即可。

> 把 `[方括号]` 换成你的真实信息；不确定的项写“不知道”，教练会先带你确认。

---

## 1. 连接 eNSP 并做首次自检

```text
你是我的网络工程实验教练。现在带我连接 eNSP，目标是先确认设备可控，再开始实验。

我的环境：
- eNSP 已启动，设备类型：[S5700 / AR2220 / 其他]
- 设备在 eNSP 里的端口：[2000，或右键设备→设置里看到的端口]
- 登录方式：[无需认证 / 用户名 admin / 其他]
- 我想做的实验：[VLAN / 静态路由 / OSPF / NAT / ACL / DHCP / STP]

请按下面顺序执行，每一步先解释目的，再调用工具，不要跳步：
1. 用 netlab_devices action=scan 扫描 127.0.0.1:2000-2020，告诉我哪些端口开放。
2. 如果我的端口没扫到，先别猜，给我一份“端口未开放”的排查清单。
3. 用 netlab_devices action=add 保存设备，id 用 [sw1]。
4. 用 netlab_exec 依次执行 display version、display clock、display current-configuration | include sysname，确认提示符、型号和配置状态。
5. 报告：设备是否可写、当前视图、下一步建议。

安全要求：只执行只读命令；不要 reboot、reset、save。遇到报错，把原始输出贴出来再分析。
```

## 2. 实验教练：让我自己配，不要直接给答案

```text
我想通过动手实验学习 [VLAN / 静态路由 / OSPF / NAT / ACL / DHCP / STP]，我的基础是 [零基础 / 配过一点 / 备考 HCIA]。

请用 netlab_lab 选一个匹配的实验，按“教练模式”带我：
1. 先给我任务书和拓扑，让我说出编址/VLAN/路由规划。
2. 我回答后，你先指出对/错，不要直接给完整配置。
3. 我卡住时，一次只给一级提示；我说“再提示”才给下一级。
4. 我每配完一小块，你用 netlab_verify 或 netlab_exec 验证，并解释输出说明了什么。
5. 全部完成后，问我 2 个“为什么”，再给一个变式练习。

约束：
- 每条配置命令都要说明它改了什么表/什么行为。
- 不要替我把所有命令一次性跑完；等我确认后再执行下一块。
- 如果设备报错，先读原始输出，不要连续重试。
```

## 3. 排障教练：分层定位，不要重置配置

```text
我的 eNSP 实验出问题了，请带我排障，不要直接 reset/reboot 或删配置。

现象：[例如 PC1 ping 不通 PC2 / OSPF 邻居卡在 Init / NAT 后上不了外网]
拓扑：[贴 ASCII 图或描述设备-接口-IP]
最近改动：[例如 刚配完 trunk / 刚改 ACL]
已经检查过：[例如 接口 UP、IP 正确]

请按分层排障执行：
1. 先列 2-3 个最可能的假设，按可能性排序，并说明每个假设的证据。
2. 每次只执行一条只读命令（display/ping/tracert），根据输出决定下一步。
3. 覆盖：物理/接口 → 二层 → 三层 → 策略 → 应用。
4. 找到根因后，只做最小改动修复；修复后用一条控制面命令 + 一条数据面测试验证。
5. 最后用 5 句话总结“下次遇到同类现象先查什么”。

如果我的描述缺少关键信息，先问我一个最关键的问题，不要一次性问十个。
```

## 4. 测验与复习：先测后讲

```text
请用 netlab_quiz 给我做一次网络工程小测：
- 主题：[VLAN, STP, OSPF, NAT, ACL, DHCP, 子网划分] 中选 [3] 个
- 题数：[8]
- 难度：[入门 / 进阶 / 混合]

规则：
1. 先只出题，不要给答案，也不要提示。
2. 我提交答案后，用 netlab_quiz action=grade 批改。
3. 对错题逐题讲：正确概念 → 我错在哪 → 一个相似变式。
4. 最后按错题主题给我一个 15 分钟复习清单。
```

## 5. 概念课：用拓扑和包走向讲原理

```text
我在学 [VLAN / ARP / STP / OSPF / NAT / ACL]，请用“一个最小拓扑 + 一个包的走向”给我讲清楚，不要只背定义。

要求：
1. 先画 2-3 台设备的最小拓扑，标出接口、IP、VLAN 或路由域。
2. 跟踪一个包从源到目的：在哪一层被封/解封装、查什么表、经过哪些设备。
3. 对比“有这项技术”和“没有这项技术”的差别。
4. 给 3 个常见误解，并逐个纠正。
5. 最后出 2 道判断题检验我是否真的理解。
```

## 6. 从零开始的一节 45 分钟实验课

```text
请给我安排一节 45 分钟的 eNSP 实验课，主题 [VLAN 互通]。
结构：
- 5 分钟：原理和拓扑
- 10 分钟：我带你把设备连上并做初始检查
- 20 分钟：我动手配置，你只给提示
- 7 分钟：验证和排障
- 3 分钟：复盘 + 一道变式题

开始前先问我：有没有已启动的 eNSP 设备？端口是多少？如果没有，先给我一份 5 步启动清单。
```

## 提示词使用小技巧

- **先给现象，再给判断**：不要只说“不通”，说清“哪台 ping 哪台、哪条命令输出什么”。
- **要求一次一条命令**：避免设备输出刷屏，也方便定位。
- **要求引用真实输出**：让教练基于 `netlab_exec` 的返回讲解，而不是凭记忆编。
- **卡住时说“给我一级提示”**：比直接说“答案是什么”学得更牢。
- **实验后说“考我”**：用 `netlab_quiz` 把刚做的实验变成 3 道题。
