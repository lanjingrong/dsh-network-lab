# 从仓库装好 dsh-network-lab 之后：连续拍 8 组命令，贴进对话框即可

> 用法：一次复制一组（两组之间隔开），粘到 DSH 对话框回车。
> 目标：第一组在 10 分钟内跑通，后面每组只练一件事。
> 前提：eNSP 已开、拓扑里至少一台 S5700 已“启动”；插件已装好并重启过 DSH。

## 第 1 组：先证明“能连上”（10 分钟）

```text
扫描 eNSP 端口，把第一台设备用 adopt 导入，然后 display version 和 display clock 各跑一次，告诉我型号和当前时间。
```

预期：Agent 依次调用 `netlab_devices action=scan` → `action=adopt` → `netlab_exec device=... commands=["display version","display clock"]`。
看 `display version` 第一行是不是你选的那台机器（S5700 还是 AR2220）。

> 如果扫描没结果：eNSP 里右键设备 → 设置 → 配置，看“串口号”，然后说：
> **“用 adopt 连 2004 端口”**，把 2004 换成实际串口号。

## 第 2 组：让它按规范给设备起名（10 分钟）

```text
按华为现场规范给我这套实验命名：站点 BJ、角色分别是核心和接入、各一台，序号从 1 开始。
再生成对应的 sysname 和接口 description 模板。
```

预期：`netlab_standard action=sysname` / `action=description`，输出形如 `BJ-CORE-01`。
**这一步别跳过**——新人最常见的现场问题就是配置里还挂着默认 `Huawei`。

## 第 3 组：做第一个实验 vlan-basic（30-40 分钟）

```text
带我做一个 vlan-basic 实验。先只给任务书，不要给答案；我卡住的时候用 netlab_lab action=hint 逐级给提示。
```

做完之后：

```text
netlab_verify lab=vlan-basic
```

没通过就让 Agent 按 verify 的 `hint` 带你查；全部变绿再进下一组。

## 第 4 组：把配置存下来，并且证明它真的存住了（15 分钟）

```text
做一个 save-compare 实验：先改一段配置、save、再用 netlab_reboot preflight 检查保存一致性。
preflight 说可以重启之后，等我确认再 reboot。
```

重点体会两件事：`save` 的 `[Y/N]`；重启后配置还在不在。
`netlab_reboot` 是两阶段的——**没经过你同意不会重启**。

## 第 5 组：故障排查，练完就测（30-45 分钟）

```text
给我一个初级故障：教学模式，先不告诉我根因。我按分层排查走，你只回答我提的问题。
```

排完再说：

```text
netlab_fault answer 给根因和它该记住的规范；
再 netlab_quiz action=grade 批改刚才那几道配套题。
```

难度不够就换 `中级` / `高级`；`f12-compound-nat` 是复合故障，适合老手。

## 第 6 组：按 HCIA 路线排下一步（5 分钟）

```text
我现在做到第几步了？netlab_curriculum action=progress，然后告诉我下一阶段该做哪个实验、要做对哪些题才算过关。
```

过关逻辑：阶段的主实验 `netlab_verify` 全绿 + 该阶段题目正确率 ≥ 80%。
没过关想强推，就要显式 `force=true`（不建议）。

## 第 7 组：报错——直接贴进对话框（随时）

```text
我在 eNSP 里敲了 [粘贴报错或命令原文]，现在 ping 不通 192.168.10.1，帮我判断踩了哪个坑。
```

插件内置 20 条 eNSP 踩坑点，会按你贴的原始报错优先匹配；口语化描述（“trunk 两边 PVID 不一样”“网关没配”）也能命中。

## 第 8 组：变成自己的学习者（长期）

```text
给我一份 14 天 HCIA 计划：每天 1-1.5 小时，第 1 天从 phase-0 的环境检查开始，按我电脑上能跑的拓扑来。
```

每完成一天就回来说 **“标记今天做完的阶段，并给我出 5 道今天内容的题”**——
进度存在本地 `progress.json` 里，重启 DSH 也不会丢。

---

## 三条“别这么做”

- **别把 VRP 命令直接敲进 DSH 对话框**（`display version` 这种），那不是工具语法；要么交给我（说“在 sw1 上跑 display version”），要么去 eNSP 控制台敲。
- **别让 Agent 自动 `save` 到刚学的那台设备**——想存就明说“save 一下”，插件默认不替你保存。
- **别在没 `save` 的情况下重启**，先用 `netlab_reboot phase=preflight` 让插件帮你比对 current 与 saved。
